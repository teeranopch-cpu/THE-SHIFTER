# **App Name**: THE CHANGERS

## Core Features:

- Player Registration & Profile Management: Enables up to five players to register their names and track individual game statistics (City Points, Life Points, problem-solving progress).
- Game Setup & Configuration: Allows players to collaboratively set the target collective City Index and a game timer, initializing game parameters with zero starting points for players.
- City Problem Interactive Module: Displays videos detailing urban issues and presents a selection of innovation cards, special cards, and surrender options for player interaction, processing immediate score impacts.
- AI-Enhanced Decision Support: Offers a generative AI tool to provide contextual analysis or key insights derived from 'City Problem' videos, aiding players in choosing solutions without revealing explicit correct answers.
- Dynamic Question & Answer System: Delivers categorized multiple-choice questions (Environment and Energy, Economy, Transportation, Living and Citizenship, Government Administration), validates player answers, and updates scores (CP/LP) in real-time.
- Real-time Score Tracking & Override: Automatically updates and displays all player and collective scores, game timer, and progress towards the City Index goal, including a warning signal if progress is insufficient. Provides a manual override for score adjustments.
- Game Conclusion & Performance Report: Evaluates final game state, calculates individual performance, identifies the high scorer, determines overall collective victory based on the target City Index, and records game history.

## Style Guidelines:

- Primary color: A vibrant, yet deep blue (#148CCC), symbolizing technology, trust, and urban development, contrasting well with the light background for clear focus.
- Background color: A very light, desaturated blue (#E4EEF2), providing a clean and approachable canvas that enhances readability without distraction.
- Accent color: A bright and lively cyan (#4EDBE7), used sparingly for interactive elements, highlights, and calls to action, evoking innovation and positive impact.
- All text will use 'Inter', a grotesque-style sans-serif font known for its modern, objective, and neutral appearance, ensuring optimal readability for game statistics and instructional text.
- Utilize a consistent set of simplified, line-art icons that are thematically aligned with urban development, civic symbols, and problem-solving actions for quick visual recognition in the game interface.
- Implement a modular, grid-based layout across all sections (Player, City Index, Video, Question) to ensure a clear hierarchy, logical flow, and responsive adaptability to different screen sizes, reflecting urban planning principles.
- Incorporate subtle feedback animations for score updates, successful answers, card selections, and timer warnings, providing immediate and satisfying visual confirmation without being distracting.
